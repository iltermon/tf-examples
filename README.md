# tf-examples

TensorFlow deep-learning examples written for my bachelor's AI class. A collection
of small, self-contained scripts covering common architectures.

## What's covered
- **CNNs** — `cnn_example.py`, `cnn_cactus.py`, `cnn_diyabet.py`, `cnn_visual.py`, `sound_cnnpy.py`
- **RNNs** — `rnn1.py`, `rnn2.py`, `rnn3.py`
- **LSTMs** — `LSTM1.py`, `LSTM2.py`, `LSTM3.py`
- **CNN + RNN/LSTM hybrids** — `cnnrnn.py`, `cnnltsm.py`, `cnnltsm2.py`
- **Cross-validation** — `cnn_crossvalidation.py`, `tensorflow_crossvalidation.py`
- **TensorFlow basics** — `tensorflow1.py`

## Running
Each script is standalone:

```bash
python cnn_example.py
```
